# 发布与回滚

| Git 标签 | 版本内容 |
| --- | --- |
| `v0.5.1` | 右键完成绘面、编辑提交后原位刷新、影像导入定位。 |
| `v0.6.0` | GDAL 原始波段代理、原生栅格符号化、图层属性同步和插件标识。 |
| `v0.7.0` | 工作站 Processing Provider、后台任务、输出归档及结果同步。 |
| `v0.8.0` | 在线地图图层拖入远程分组后同步，本地数据拖入时恢复位置并提示。 |
| `v1.0.0-rc1` | 汇总上述模块的安装包、使用说明、处理功能清单和回归验证。 |

安装版本回滚时，先保存编辑并停止工作站服务，再在两端 QGIS 中安装同一份旧 ZIP。各阶段归档在 `dist/`。工作站项目与数据由 QGIS 保存在原路径，使用旧插件前先考虑该版本对新增在线源和属性的支持范围。

需要检查任一 Git 历史版本时，可以使用单独的工作树。例如在本仓库父目录创建一个旧版目录。

```sh
git worktree add --detach ../RemoteQGIS-v0.5.1 v0.5.1
```

正式发布需在 Windows 工作站和 macOS 客户端完成跨网验收，覆盖真实遥感影像的原始波段访问、工作站 GDAL 算法及在线服务可达性。
