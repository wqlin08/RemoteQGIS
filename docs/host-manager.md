# RemoteQGIS Host Manager

Host Manager 使用工作站已安装的 QGIS 3.40 或更新的 3.x 版本。管理服务可以在登录后静默运行。客户端发起自动连接时，管理服务打开独立配置中的 QGIS Desktop，由其中的 RemoteQGIS 工作站面板提供 GIS 服务。远端屏幕显示同一项目，可同步图层和地图范围。托管 Host 作为普通插件从隔离的 QGIS 配置加载。

## 安装与首次配置

Windows x64 双击发行文件 `RemoteQGIS-Host-Manager-Windows-x64-1.1.0-rc7-Setup.exe`。安装完成后，选择 QGIS 的安装目录，例如 `D:\QGIS`。程序会检查该目录中的 QGIS Desktop 与 Python 启动脚本。升级前退出旧管理服务，并退出管理界面。Windows 安装程序会建立当前用户的开始菜单入口。

macOS 解压发行 ZIP，将 `RemoteQGIS Host Manager.app` 放入「应用程序」。首次打开时选择已安装的 `QGIS-LTR.app` 或 `QGIS.app`。构建和测试时可通过 `REMOTEQGIS_QGIS_APP` 指定安装路径。

在 Host Manager 中配置默认授权目录，可同时填写多个「其他授权目录」，每行一个。启动项目可留空。跨设备使用时，监听地址填写工作站自己的 Tailscale 或 VPN 地址。GIS 端口默认 8765，管理端口默认 8766。点击「保存并启动管理服务」。访问令牌和本地控制凭据由系统凭据库保存。令牌栏的「复制」按钮可直接复制当前服务令牌。

## 连接及工作空间

客户端从 ZIP 安装同版本的 QGIS 插件。在 Client 标签页填写工作站地址、GIS 端口、管理端口及令牌，点击「连接」。也可将该工作站保存为 Host Manager 类型，再用「连接工作站」启动和连接。管理服务拒绝凭据时，从同一台工作站的 Host Manager 复制当前令牌，粘贴后重试。手动开启旧版 QGIS Host 时，使用「直接连接 GIS」。

连接后，在「远程工作区」点击「工作空间」，可以进入已配置的其他授权目录或浏览它们的子目录，最后选择「使用当前目录」。选择会保存在工作站。切换时会清空当前远端项目，未保存的项目、进行中的矢量编辑或处理任务会阻止切换。文件浏览和处理输出均以当前工作空间为基准。在客户端调整 RemoteQGIS 分组里的图层顺序，远端图层树和绘制顺序会同步更新。

关闭远端 QGIS 或退出管理服务时，QGIS 的保存提示用于确认未保存项目。选择取消会中止关闭，远端 QGIS、Host 和未保存项目继续保留。

管理器在托管插件确认 GIS 端口已监听后显示「QGIS Desktop 已就绪」。若启动较慢，窗口显示当前的 Python、托管插件或 GIS 服务阶段。`host.log` 记录每次启动的进程号与时间，可区分不同尝试中的就绪和异常。启动超时会保留该窗口。主动请求关闭后，如 QGIS 尚未确认，管理器会提示在工作站查看保存对话框或从 QGIS 菜单退出。Windows 初次启动失败时，可在「打开日志目录」中查看 `launcher.log`、`manager-crash.log`、`manager.log` 和 `host.log`。

影像默认按需读取原始波段。选中远端影像图层，在「显示方式」中可切换到「快速瓦片预览」或重试原始波段。瓦片由工作站渲染，原始像元查询仍读取工作站数据。使用原生波段属性、分类色表或伪彩色编辑时切回原始波段。

## 自启与维护

开启「登录后自动启动并在系统托盘驻留」并保存后，用户登录时会出现托盘图标。管理服务等监听地址就绪后开始监听。关闭设置窗口会隐藏到托盘，双击图标或选择「打开设置」可以恢复窗口。托盘菜单提供「退出管理服务」和「退出管理界面」。授权目录和令牌的变更须在退出管理服务后保存。由旧版迁移时，在新版界面确认自启并保存，以更新登录启动项。常规配置及日志位于 macOS 的 `~/Library/Application Support/RemoteQGIS Host` 或 Windows 的 `%LOCALAPPDATA%\RemoteQGIS Host`。

Windows 实机可使用临时目录完成验收。安装后确认选择的 QGIS 路径和两个端口，从 macOS 连接，观察工作站自动打开 QGIS；再导入影像、切换显示模式和工作空间，并检查日志及项目保存。验证登录自启时，可检查登录后管理服务在线且 QGIS 尚未打开，随后发起自动连接。

软件依赖已安装的 QGIS 3.x 和可用的用户桌面会话。Windows 安装程序尚未做开发者签名，macOS 应用尚未公证。
