# RemoteQGIS Host Manager

Host Manager 使用工作站已安装的 QGIS 3.40 或更新的 3.x 版本。管理服务可以在登录后静默运行。客户端发起自动连接时，管理服务打开独立配置中的 QGIS Desktop，由其中的 RemoteQGIS 工作站面板提供 GIS 服务。远端屏幕显示同一项目，可同步图层和地图范围。托管 Host 作为普通插件从隔离的 QGIS 配置加载。

## 安装与首次配置

Windows x64 双击发行文件 `RemoteQGIS-Host-Manager-Windows-x64-1.1.0-rc4-Setup.exe`。安装完成后，选择 QGIS 的安装目录，例如 `D:\QGIS`。程序会检查该目录中的 QGIS Desktop 与 Python 启动脚本。由旧便携版升级时，先在旧窗口退出管理服务，再关闭窗口。Windows 安装程序会建立当前用户的开始菜单入口。

macOS 解压发行 ZIP，将 `RemoteQGIS Host Manager.app` 放入「应用程序」。首次打开时选择已安装的 `QGIS-LTR.app` 或 `QGIS.app`。构建和测试时可通过 `REMOTEQGIS_QGIS_APP` 指定安装路径。

在 Host Manager 中选择允许客户端访问的授权目录，可选启动项目。跨设备使用时，监听地址填写工作站自己的 Tailscale 或 VPN 地址。GIS 端口默认 8765，管理端口默认 8766。点击「保存并启动管理服务」。访问令牌和本地控制凭据由系统凭据库保存。令牌栏的「复制」按钮在密码隐藏时也能使用。

## 连接及工作空间

客户端从 ZIP 安装同版本的 QGIS 插件。在 Client 标签页填写工作站地址、GIS 端口、管理端口及令牌，点击「启动远端并连接」。也可将该工作站保存为 Host Manager 类型，再用「连接工作站」启动和连接。管理器检测远端 QGIS 就绪后，客户端进入正常 GIS 连接。手动开启旧版 QGIS Host 时，仍可使用「连接」按钮。

连接后，在「远程工作区」点击「工作空间」，浏览授权目录及其子目录，并选择「使用当前目录」。选定的目录作为 GIS 工作区并保存在工作站。切换时会清空当前远端项目，未保存的项目、进行中的矢量编辑或处理任务会阻止切换。可先保存项目或等待任务完成，再切换。文件浏览和处理输出均以当前工作空间为基准。在客户端调整 RemoteQGIS 分组里的图层顺序，远端图层树和绘制顺序会同步更新。

关闭远端 QGIS 或退出管理服务时，QGIS 的保存提示用于确认未保存项目。选择取消会中止关闭，远端 QGIS、Host 和未保存项目继续保留。

影像默认按需读取原始波段。选中远端影像图层，在「显示方式」中可切换到「快速瓦片预览」或重试原始波段。瓦片由工作站渲染，原始像元查询仍读取工作站数据。使用原生波段属性、分类色表或伪彩色编辑时切回原始波段。

## 自启与维护

开启「登录时启动管理服务」后，后续登录会自动启动管理服务，QGIS Desktop 在客户端发起自动连接时打开。切换自启设置、授权目录或访问令牌时，先退出管理服务。若从旧版迁移登录自启，安装新版后应在新版管理窗口确认自启并保存，以更新启动路径。关闭远端 QGIS 时，QGIS 自身会提示处理未保存的项目；选择取消不会终止远端会话。常规配置及日志位于 macOS 的 `~/Library/Application Support/RemoteQGIS Host` 或 Windows 的 `%LOCALAPPDATA%\RemoteQGIS Host`。

Windows 实机可使用临时目录完成验收。安装后确认选择的 QGIS 路径和两个端口，从 macOS 连接，观察工作站自动打开 QGIS；再导入影像、切换显示模式和工作空间，并检查日志及项目保存。验证登录自启时，可检查登录后管理服务在线且 QGIS 尚未打开，随后发起自动连接。

软件依赖已安装的 QGIS 3.x 和可用的用户桌面会话。Windows 安装程序尚未做开发者签名，macOS 应用尚未公证。
