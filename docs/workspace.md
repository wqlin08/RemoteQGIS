# 工作区实现

## 远端项目与文件

HTTP 接口验证访问令牌。工作区请求通过 Qt 排队信号调度到工作站主线程操作 PyQGIS。共享文件采用根目录相对路径，拒绝绝对路径、父目录跳转、符号链接、重解析点及保留文件名。移动和回收 Shapefile 时处理相关副文件。工作站当前使用的数据或项目禁止移动和回收。导入后根据工作站图层 ID 创建本机代理，GeoPackage 内的多个矢量表可分别建层。

工作区状态包含会话 ID 与单调递增的项目修订号。WebSocket 发送更新提示，客户端根据上次修订号读取新增、变更、移除的图层，以及变更后的图层树结构。工作站保留最近 16 个修订的摘要供增量请求选择。图层树同步由客户端和工作站分别维护应用后的状态，以减少循环更新。项目保存使用工作站的真实数据源。远程打开项目时验证项目内的数据源范围。客户端视野交互在本地执行，地图范围和旋转经防抖同步至工作站。

## 遥感影像

工作站提供经过认证的 GeoTIFF 字节范围接口，读取目标由图层 ID 和数据版本确定。客户端建立临时 GDAL VRT 与回环中转，QGIS 原生栅格提供器通过 VRT 按需访问源像元。工作站令牌留在插件连接中，VRT 使用本机临时端口。原始数据、图层 CRS 与波段信息用于 QGIS 的栅格符号化、色表和像元访问。

客户端和工作站交换可导出的 QGIS 样式。栅格支持分类调色板、单波段伪彩色、灰度、RGB 和 QGIS 内置外观、图例及渲染设置。矢量同步经过筛选的原生符号、标签及渲染设置。旧版工作站可继续通过 XYZ 方式显示。原始像元查询仍由工作站直接读源栅格。

## 在线图层

只有从分组外移入的公共 HTTP(S) XYZ、WMS 或 WMTS 连接才提交同步。工作站保留公开服务的连接信息，各端向该服务发起自身的地图请求。工作站项目文件保存在线图层的位置、可见性和可同步显示参数。客户端将原图层登记为代理，解除同步或断开时恢复此前的本地位置。

## 远程计算

客户端原生 Processing Provider 从工作站读取可用算法，以工作站图层 ID 解析本机代理。工作站将数据源限定为共享目录中已加载的真实输入，并通过 QGIS 后台任务运行原生算法。输出先写入共享目录内暂存区，再移动到用户指定位置并加入项目。算法白名单和参数边界见[远程 Processing 清单](processing.md)。

## 矢量编辑与恢复

矢量代理基于 QGIS 内存图层，支持原生编辑缓冲、捕捉和撤销重做。启用编辑后，已有要素持有工作站生成的 `rq_uuid`。客户端在当前代理内通过 FID 到 UUID 的映射识别已有要素，新要素在生成事务时分配 UUID。GeoPackage 的原生主键由驱动维护。

客户端在保存本机编辑时生成新增、更新、删除和字段定义，并把事务及工作数据写入本地恢复文件，工作站成功确认后删除记录。存储路径按端点和数据源隔离。工作站检查基础数据版本和事务标识。GeoPackage 通过 OGR 事务原子提交，Shapefile 在暂存文件组上编辑，工作站在 `.remoteqgis-edits` 保留原文件组备份。成功事务的凭据用于识别网络重试，工作站拒绝基于过期数据版本提交的事务，客户端保留本地工作数据。

## 当前范围

工作区读取每个矢量代理的完整要素，单图层上限为 20,000 要素，单个 JSON 请求或响应上限为 32 MiB。远端项目打开支持共享目录内的 GeoTIFF、GeoPackage、Shapefile 和通过连接校验的在线栅格。矢量脚本属性表单、外部 SVG 或字体资产、栅格源路径切换、远程金字塔构建及数据源专有扩展暂未双向同步。原始波段代理的读取速度取决于影像分块、概览和网络条件。

在线同步当前覆盖无凭据的公共 XYZ、WMS、WMTS。WFS、在线矢量瓦片、ArcGIS 专有服务、本机与内网地址、API 密钥及身份验证配置暂未接入。每台设备都需能访问所用在线服务。

Shapefile 暂存校验后的多文件替换依赖本地文件系统，失败时会尝试还原原文件组。若工作站在替换期间退出，可从工作站的备份恢复。极短的写入完成与凭据落盘窗口发生异常时，需要核对工作站数据版本后再处理客户端记录。现场 Windows 文件锁、跨网延迟与吞吐仍待实机验收。
