# V0.5 工作区实现

## 远端项目与文件

HTTP 接口验证访问令牌。工作区请求通过 Qt 排队信号调度到工作站主线程操作 PyQGIS。共享文件采用根目录相对路径，拒绝绝对路径、父目录跳转、符号链接、重解析点及保留文件名。移动和回收 Shapefile 时处理相关副文件。工作站当前使用的数据或项目禁止移动和回收。导入后根据工作站图层 ID 创建本机代理，GeoPackage 内的多个矢量表可分别建层。

工作区状态包含会话 ID 与单调递增的项目修订号。WebSocket 发送更新提示，客户端根据上次修订号读取新增、变更、移除的图层，以及变更后的图层树结构。工作站保留最近 16 个修订的摘要供增量请求选择。图层树同步由客户端和工作站分别维护应用后的状态，以减少循环更新。项目保存使用工作站的真实数据源。远程打开项目时验证项目内的数据源范围。客户端视野交互在本地执行，地图范围和旋转经防抖同步至工作站。

## 遥感影像

工作站用 GDAL 以小型输出网格读取和转换 GeoTIFF 的可见部分，利用影像已有内部或外部概览。动态瓦片为 EPSG:3857 下的 256 × 256 PNG，由 QGIS 原生 XYZ 提供器请求。Tile URL 包含图层标识、数据及概览指纹、波段、颜色拉伸、NoData 和重采样版本。工作站内存缓存保留近期瓦片，客户端使用 QGIS 网络缓存，并在视野稳定后预取相邻瓦片。原始像元接口对工作站数据执行坐标到行列的换算，读取源像元。

## 矢量编辑与恢复

矢量代理基于 QGIS 内存图层，支持原生编辑缓冲、捕捉和撤销重做。启用编辑后，已有要素持有工作站生成的 `rq_uuid`。客户端在当前代理内通过 FID 到 UUID 的映射识别已有要素，新要素在生成事务时分配 UUID。GeoPackage 的原生主键由驱动维护。

客户端在保存本机编辑时生成新增、更新、删除和字段定义，并把事务及工作数据写入本地恢复文件，工作站成功确认后删除记录。存储路径按端点和数据源隔离。工作站检查基础数据版本和事务标识。GeoPackage 通过 OGR 事务原子提交，Shapefile 在暂存文件组上编辑，工作站在 `.remoteqgis-edits` 保留原文件组备份。成功事务的凭据用于识别网络重试，工作站拒绝基于过期数据版本提交的事务，客户端保留本地工作数据。

## 当前范围

V0.5 完整载入每个矢量代理，单图层上限为 20,000 要素，单个请求或响应上限为 32 MiB。远端项目打开支持共享目录内的 GeoTIFF、GeoPackage、Shapefile；矢量样式同步覆盖使用基本点、线、面符号的常见渲染器，影像支持单波段灰度和三波段 RGB。复杂表达式符号、外部样式资产、大型矢量按范围加载和远程 Processing 仍属后续范围。

Shapefile 暂存校验后的多文件替换依赖本地文件系统，失败时会尝试还原原文件组。若工作站在替换期间退出，可从工作站的备份恢复。极短的写入完成与凭据落盘窗口发生异常时，需要核对工作站数据版本后再处理客户端记录。现场 Windows 文件锁、跨网延迟与吞吐仍待实机验收。
